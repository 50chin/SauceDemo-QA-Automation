# SauceDemo QA Automation Framework

## 📌 О проекте
Учебный фреймворк для автоматизации тестирования. Включает в себя UI-тесты (Selenide) и API-тесты (RestAssured) на языке Java. Проект создан для демонстрации навыков написания автотестов, работы с Maven и JUnit 5.

## 🛠 Технологии и инструменты
- **Язык:** Java 21
- **UI-автоматизация:** Selenide
- **API-автоматизация:** RestAssured
- **Фреймворк для тестов:** JUnit 5
- **Сборка:** Maven
- **Система контроля версий:** Git

## 🧪 Реализованные тесты

### UI-тесты (SauceDemo)
- `testSuccessfulLogin()` — проверка успешной авторизации.
- `testInvalidLogin()` — проверка ошибки при неверном пароле.
- `testAddToCart()` — добавление товара в корзину.
- `testRemoveFromCart()` — удаление товара из корзины.
- `testSortByPriceLowToHigh()` — сортировка цен по возрастанию.
- `testSortByPriceHighToLow()` — сортировка цен по убыванию.
- `testCheckoutProcess()` — E2E-тест полного оформления заказа.

### API-тесты (JSONPlaceholder)
- `testGetSinglePost()` — проверка получения валидного поста (статус 200).
- `testGetNonExistingPost()` — проверка несуществующего поста (статус 404).

## 🚀 Как запустить
1. Клонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Дождитесь загрузки зависимостей Maven.
4. Запустите тесты через терминал: `mvn test`
